# summarise and check

read the files in {INBOX}. summarise them, then check your own summary against
the source.

## summarise

- read every .md file in the folder
- one paragraph per file, no more, no preamble
- keep the file name as the heading

## check

- for each claim, point at the line in the source that backs it

## deleted

anything taken out in the check pass, one line each, with why.

put a blank line between the sections. output markdown, nothing else.
